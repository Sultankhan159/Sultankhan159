|:--|:--|
| **Linear Algebra** | Vectors, matrices, eigenvalues — the language of data & neural nets |
| **Calculus** | Derivatives & gradients — how models learn (gradient descent) |
| **Probability** | Uncertainty, Bayes' theorem, distributions |
| **Statistics** | Hypothesis testing, variance, correlation, confidence intervals |
